# Software Environments and Module Management

**Sagehen HPC Cluster Workshop: Pomona College ITS**

Welcome to the Software Environments and Module Management workshop! This course teaches you how to effectively use the module system (Lmod) and Python environments on Sagehen, Pomona College's high-performance computing cluster.

## Who This Course Is For

This workshop is designed for researchers and students who want to:

- Use complex scientific software on Sagehen without conflicts
- Manage multiple versions of the same software
- Create reproducible Python environments for your research
- Share your analysis workflow with collaborators
- Write robust batch scripts for long-running computations

## What You'll Learn

By the end of this workshop, you will be able to:
- Use the Lmod module system to load and manage software
- Find software and check documentation
- Create and restore personal module collections
- Build isolated Python environments using conda
- Use virtual environments and pip effectively
- Follow best practices for reproducible research computing

## Workshop Structure

This workshop consists of six episodes covering:

1. **Lmod Basics**: Understanding environment modules and core commands
2. **Finding Software**: Discovering available modules and learning about them
3. **Managing Modules**: Loading multiple modules, swapping versions, saving collections
4. **Conda Environments**: Creating isolated Python/R environments
5. **Pip and Virtual Environments**: Alternative Python package management
6. **Best Practices**: Writing reproducible, shareable workflows

Each episode combines teaching with hands-on exercises. You'll need SSH access to Sagehen and a text editor.

## Prerequisites

You should be comfortable with:

- Basic Linux command-line operations (navigating directories, running commands)
- Using SSH to connect to remote systems
- Using a text editor (vi, nano, VS Code, etc.)

## Before You Start

You'll need:

- An active Sagehen account with SSH access
- Basic familiarity with the Linux command line
- A terminal application (Terminal on macOS, PowerShell on Windows, or Linux terminal)

If you need an account, submit the [HPC account request form](https://servicedesk.pomona.edu/support/catalog/items/83); for password resets or other issues, contact its-hpc@pomona.edu.
